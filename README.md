# Sky-Queue
Sky‑Queue 是机场安检通道智能排队AI助手。 系统通过摄像头视觉识别，实时统计多条安检通道内的旅客数量，自动计算预估等待时长；借助智能分流算法，给出通行参考建议，帮助旅客合理选择通道，缓解场站排队拥堵压力。（项目预计于2027 Q2正式上线）
